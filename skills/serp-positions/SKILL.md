# Позиции и выдача

Инструменты сервера `jsonseo`: `yandex_search`, `google_search`, `bing_search`,
`yandex_position`, `google_position`, `bing_position`, `yandex_suggest`,
`google_suggest`, `bing_suggest`, `yandex_regions`, `google_regions`.

## Порядок работы

1. **Определи регион.** Если пользователь назвал город, область или страну —
   сначала найди идентификатор:
   - Яндекс: `yandex_regions` по названию → числовой `region` (Казань → 43).
     Он же возвращает координаты `lat`/`lon` — они нужны для Bing.
   - Google: `google_regions` по названию → числовой `region` (Москва → 1011969)
     и те же координаты.
   - Bing регионов не знает: точку задавай `lat`/`lon` из любого справочника
     выше, страну и язык — рынком `mkt` (например `en-US`; по умолчанию
     `ru-RU`).
   Справочники бесплатны. Если регион не назван — у Яндекса и Google по
   умолчанию Москва (213 и 1011969); скажи об этом пользователю или уточни
   регион, не выдавай московскую позицию за «без региона».
2. **Выбери экономный инструмент.**
   - Нужен только номер позиции сайта → `*_position` с `domain`. Поиск
     остановится на искомом сайте, спишется только за просмотренные страницы.
   - Нужен список конкурентов без сниппетов → `*_search` с `compact: true`
     (позиция, домен, URL).
   - Нужна выдача только до определённого сайта → `break_domain`.
   - Полную выдачу со сниппетами бери только когда пользователь просит
     разобрать содержимое сниппетов, заголовки или описания.
3. **Национальная выдача Яндекса** — задавай `zone` (by, kz, com.tr…) вместе
   с `region`: зона без региона даёт неполный национальный эффект.
4. **Сравнение поисковиков** — один и тот же запрос в `yandex_*`, `google_*`,
   `bing_*` с одинаковой геолокацией; сведи в таблицу «поисковик — позиция».

## Тарификация и предупреждения

- 0,01 ₽ за страницу выдачи, 0,01 ₽ за запрос подсказок, регионы бесплатны.
- У `*_search` по умолчанию одна страница (топ-10); больше — только если
  пользователь явно просит глубину (топ-30, топ-50): укажи `pages`.
- У `*_position` по умолчанию до **10 страниц** (топ-100): если сайта нет в
  выдаче, спишется за все десять. Когда пользователя интересует только топ-10
  или топ-30, передай `pages: 1` или `pages: 3`.
- Если сайта нет в просмотренной глубине, инструмент `*_position` так и
  сообщит: не запрашивай полную выдачу «на всякий случай», скажи, до какой
  страницы искали, и спроси, нужно ли глубже.
- Если сервер вернул ошибку авторизации или нехватки баланса — передай текст
  пользователю и попроси проверить API-ключ и баланс на jsonseo.ru. Не
  повторяй вызов автоматически.

## Формат ответа

Коротко: позиция, поисковик, регион, дата проверки. Для выдачи — нумерованный
список «позиция — домен — заголовок» без копирования сниппетов целиком, если
их не просили.
