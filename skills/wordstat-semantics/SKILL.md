# Семантика по Вордстату

Инструменты сервера `jsonseo`: `wordstat`, `wordstat_frequency`,
`wordstat_graph`, `wordstat_map`, а также `*_suggest` для подсказок.

## Какой инструмент брать

| Задача | Инструмент |
| - | - |
| Частотность одной фразы числом | `wordstat_frequency` |
| Расширить ядро: вложенные и похожие запросы | `wordstat` (колонки `popular` и `associations`, размер — `limit`) |
| Сезонность, тренд, динамика | `wordstat_graph` (`graph_type`: `month` по умолчанию, `week`, `day` — последние 60 дней; `last` — последние N точек) |
| Спрос по регионам и городам | `wordstat_map` (`map_type`: regions, cities, all) |
| Идеи формулировок из автодополнения | `yandex_suggest`, `google_suggest`, `bing_suggest` |

Регион для `wordstat`, `wordstat_frequency`, `wordstat_graph` — тот же ID,
что у Яндекса (найди через `yandex_regions`), но передаётся **строкой**:
`"213"` или несколько через запятую `"213,2"`. У `wordstat_map` региона нет —
он сам раскладывает по всем.

Параметр `kind` есть не только у `wordstat_frequency`: `wordstat_graph` и
`wordstat_map` тоже его принимают, но по умолчанию считают **базовую**
частотность. Для сезонности или географии точного спроса передавай
`kind: exact` явно.

## Вид частотности (`kind` у `wordstat_frequency`)

- `exact` (по умолчанию) — точная «"!слово !слово"»: ровно эта фраза в этих
  словоформах. Для прогноза трафика, приоритезации и когда пользователь просто
  спрашивает «какая частотность» — всегда она.
- `base` — базовая: любые формы, порядок и хвосты. Только для оценки объёма
  ниши; как прогноз трафика завышена в разы. Колонки `wordstat` показывают
  именно базовую — для приоритезации не подходит.
- `phrase` — фразовая «"фраза"»: состав слов зафиксирован, формы и порядок
  плавают. Спрос на формулировку без хвостов.
- `superexact` — сверхточная «"[!слово !слово]"»: ещё и порядок слов. Только
  когда порядок меняет смысл («билеты москва казань» и обратно).

Фразу передавай без операторов — сервер расставит их сам по `kind`.

**Проверка на пустышку:** сними `base` и `exact`; если `exact` близка к нулю
при большой `base` — в таком виде фразу не ищут, спрос живёт в хвостах
(их покажет `wordstat` в колонке `popular`).

## Порядок сбора ядра

1. Уточни регион и возьми ID через `yandex_regions`.
2. По каждой маркерной фразе — `wordstat` с разумным `limit` (20–50).
3. Отфильтруй мусор и дубли, затем для оставшихся фраз сними точную
   частотность `wordstat_frequency` (`kind: exact`). Не снимай точную для сотен
   фраз без запроса пользователя — каждый вызов платный (0,01 ₽), предупреди
   о количестве вызовов, если их больше 50.
4. При необходимости проверь сезонность ключевых фраз `wordstat_graph`.
5. Отдай таблицу «фраза — базовая — точная — регион» и короткие выводы.

## Тарификация

0,01 ₽ за каждый запрос к Вордстату и подсказкам; `wordstat_frequency` —
отдельный запрос от `wordstat`. Регионы бесплатны. При ошибке авторизации или
нехватке баланса — передай текст ошибки пользователю, не повторяй вызов.
